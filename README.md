# ARAM by Astrid — Landing page

Sitio web para la marca personal de Astrid como coach de fuerza, yoga, movilidad y bienestar. **No es una tienda de ropa.**

## Inicio
Abre `index.html` en un navegador o sirve la carpeta con `python -m http.server 8000`.

## Publicación
Se puede desplegar como sitio estático en Vercel, Netlify o GitHub Pages. El directorio raíz contiene `index.html`.

## Antes de producción
- Sustituir el isotipo SVG conceptual por el vector oficial exacto de ARAM.
- Incorporar fotos reales y biografía/certificaciones confirmadas de Astrid.
- Conectar el formulario a un backend, correo o WhatsApp (actualmente es una demostración sin envío).
- Confirmar modalidades, horarios, redes sociales y datos de contacto.
- Reemplazar las imágenes externas de referencia por fotografías autorizadas.
